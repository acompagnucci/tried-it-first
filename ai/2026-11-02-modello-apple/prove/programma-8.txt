=== Risposta ===
Il bug risiede nel confronto tra il valore di pagamento (`pagato`) e il valore totale dell'importo della fattura (`f.importo()`).

La differenza tra i due valori è calcolata con `!pagato.equals(f.importo())`, il che è equivalente a `!pagato.compareTo(f.importo()) < 0`. Questo confronto restituisce `false` anche se il valore di pagamento è esattamente uguale a quello previsto (es. `120.00 == 120.00`). Di conseguenza, la fattura `F-001` viene erroneamente segnalata come non saldata perché il suo valore di pagamento (`120`) è uguale a quello atteso (`120`), anche se non è inferiore.

La correzione più piccola possibile è modificare la condizione da `!pagato.equals(f.importo())` a `!pagato.compareTo(f.importo()) < 0`.

```java
public class ControlloPagamenti {

    // ... (resto del codice)

    static List<String> fattureNonSaldate(List<Fattura> fatture, List<Pagamento> pagamenti) {
        Map<String, BigDecimal> totalePagato = new HashMap<>();
        for (Pagamento p : pagamenti) {
            totalePagato.merge(p.numeroFattura(), p.importo(), BigDecimal::add);
        }

        List<String> nonSaldate = new ArrayList<>();
        for (Fattura f : fatture) {
            BigDecimal pagato = totalePagato.getOrDefault(f.numero(), BigDecimal.ZERO);
            if (!pagato.compareTo(f.importo()) < 0) {
                nonSaldate.add(f.numero());
            }
        }
        return nonSaldate;
    }

    // ... (resto del codice)
}
```
